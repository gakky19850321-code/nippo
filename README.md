# 日報

作業時間を記録して、区分別・案件別・期間別に集計できる日報アプリです。

## 使い方

公開URL: https://gakky19850321-code.github.io/nippo/

- 「今から記録を始める」で開始時刻が入り、「終了する」で終わります
- 「集計」タブで、今週・今月などの合計と、区分別・案件別の内訳が見られます
- 「設定」タブで、作業の区分（名前と色）を変えられます

## 保存について

- 記録は、開いた端末のブラウザの中（localStorage）に保存されます。サーバーには送信されません
- そのため、別の端末やブラウザとは共有されません
- ブラウザの閲覧データ（サイトデータ）を消すと記録も消えます。「集計」タブからCSVを書き出して控えを残せます

## 構成

`index.html` の1ファイルだけで動きます。ビルドや外部サービスは不要です。
